# 업무방 현황판

Claude Code 세션 여러 개를 사무실 그림 하나로 보는 현황판이에요. 프로젝트 폴더 하나가 회의실 하나이고, 세션 하나가 사람 한 명으로 앉아 있어요.

- **평면도:** 회의실이 줄마다 늘어서 있고 사이사이 복도가 있어요. 사람마다 표정과 작은 말풍선으로 지금 상태(일하는 중, 승인 대기, 답변 대기, 내 차례, 막힘)와 최근에 한 말을 보여 줘요.
- **회의실 안:** 회의실을 누르면 확대되면서 안으로 들어가요. 자리가 넓게 바뀌고, 말풍선에 최근에 한 말이 9줄까지 보여요(마우스를 올리면 전부). 말풍선을 누르면 그 사람이 최근에 한 말이 큰 카드로 나와요.
- **회의록:** 회의실 안 오른쪽에 회의록이 쌓여요. 지시, 말, 보고, 세션 간 메시지, 회의 진행을 시간순으로 보여 주고, "회의록 저장"으로 .md 파일을 받을 수 있어요.
- **오케스트레이션 회의:** 의장 세션이 회의 상태 파일을 남기면 화이트보드에 안건과 라운드가, 명패에 역할 이름이 나와요.
- **패널 메뉴:** 패널 맨 위의 **확인할 일 · 직원 · 회의록 · 일감 · 보고** 탭을 누르면 그 카드만 보이고, 같은 탭을 다시 누르면 패널이 접혀요(탭 숫자는 남은 확인할 일·직원 수). 탭 막대 오른쪽 ⤓/⤒ 로 메뉴를 **화면 아래 떠 있는 막대**로 옮기거나 다시 패널 위로 올려요. 아래로 두면 사무실이 화면 폭을 다 쓰고 패널은 막대 위로 열려요(Esc 로 닫힘). 처음엔 폰이 아래·접힘, PC 가 위예요. 방에 들어가면 회의록 탭으로 바뀌고 그 방 회의록이 맨 위, 그 아래 전체 회의록 트리("모두 접기" 단추)가 와요.
- **오른쪽 패널:** 카드 제목(확인할 일·직원·회의록)을 누르면 접혀요. **확인할 일**은 승인 대기·질문·막힘·완료 보고 갈래로 나뉘고, 갈래 머리줄도 접을 수 있어요. 카드 오른쪽 아래 **확인**을 누르면 목록과 위 숫자에서 빠지고(갈래마다 "모두 확인"), 그 세션 상태가 바뀌면(새 보고·새 질문) 다시 떠요. 치운 것은 "확인한 것 n건 보기"에서 되살릴 수 있어요. 서버로 연 현황판에서 확인하거나 그 세션에 답(빠른 답·지시 보내기·텔레그램)을 보내면 PC·폰과 다른 컴퓨터 현황판에서도 같이 사라져요 (서버의 `acks.json`, 다른 컴퓨터는 동기화로 1~2분, 되살리기도 같이). 텔레그램 다시 알림도 안 와요. **직원**은 `층(컴퓨터) ▸ 파트(방) ▸ 직원(세션)` 명부예요. 전체·일하는 중·내 차례·대기로 거르고, 사람을 누르면 세션 창(지시 보내기)이 열려요. 접은 상태와 '확인'은 그 브라우저에만 기억해요(PC 와 폰은 따로). 방에 들어가면 위에 그 방 카드(이 방 직원·회의록)가 오고, 확인할 일·직원 카드는 그 아래에 그대로 있어요. 폰 3D 에서는 오른쪽 위 **목록** 단추로 패널까지 바로 내려가요. 방에서 나올 때는 화면 왼쪽 위나 방 패널 맨 위의 **← 방 나가기**, 컴퓨터는 Esc, 폰은 뒤로 가기로도 돼요.
- **화면 배치:** 위쪽 단추로 "꽉 차게"(화면 폭을 끝까지 씀), "패널 ⇄"(오른쪽 패널을 왼쪽으로), "패널 숨김"을 고르고, 패널 가장자리를 끌어서 폭을 바꿔요.

## 3D 사무실 (2D/3D 단추)

`office3d.js`가 같은 기록으로 3D 사무실을 그려요. Three.js(r149)를 jsDelivr에서 불러오므로 인터넷이 필요해요. 링크 끝에 `?d=3d`를 붙이면 바로 3D로 열려요.

- **사람이 실제 상태대로 움직여요.**
  - 일하는 중: 자기 자리에서 타자를 쳐요. 방금 말했으면 손짓하며 말하고, 회의 의장은 화이트보드 앞에서 발표해요.
  - 승인·답변 대기: 대표실 책상 앞에 와서 줄을 서고 손을 흔들거나 들어요.
  - 막힘: 자리에서 일어나 머리를 짚어요.
  - 일 없이 10분 넘음: 15~30분에 한 번 가까운 탕비실로 다녀와요. 한꺼번에는 쉬는 사람의 4분의 1까지만 가요.
  - 30분 넘음: 수면실 침대에서 일이 생길 때까지 자요.
  - 새 세션·끝난 세션: 엘리베이터로 오가요. 워커(서브에이전트)는 로봇이고, 문으로 들어와 앉아요. 새 사람은 자리에 닿으면 👋 하고 손을 흔들어요.
  - 이번 차례에 커밋을 했으면 잠깐 손을 흔들며 머리 위에 🎉 가 떠요.
  - 머리 옆 이름표 바탕은 그 층 색이에요(집 컴퓨터 파랑 등, 연하게).
- **사무실:**
  - 회의실이 줄마다 늘어서고, 줄 끝마다 탕비실이 있어요.
  - 아래쪽에 대표실·휴게실·수면실이 있어요.
  - 컴퓨터가 여럿이면 컴퓨터마다 층으로 나뉘어요. 층 앞 가로 띠에 층 이름을 크게 칠하고 옆에 작게 "이 컴퓨터" 또는 "n분 전 동기화"를 써요. 건물 맨 왼쪽 띠에는 층마다 그 층 방들이 이어지는 만큼 세로 색 줄이 있고, 층 이름과 동기화를 눕혀 써요.
- **대표 (나):**
  - 대표실 책상에 앉아 있는 ★ 캐릭터예요.
  - 누르면 골라지고, 바닥을 누르면 그리로 걸어가요.
  - 어떤 캐릭터를 쓸지는 "조명" 판의 ◀ ▶로 골라요.
- **조명 판:**
  - 사무실 색 테마를 바꿔요(파스텔·우드·모던·밤).
  - 밝기와 빛 색(차갑게↔따뜻하게)을 조절해요.
- **움직이기:**
  - 끌면 이동, 오른쪽 버튼으로 끌면 회전, 휠로 확대해요. 폰은 한 손가락·두 손가락으로 해요.
  - 방을 누르면 그 회의실로 들어가 회의록을 봐요.
- **손(도구 막대 ✋):**
  - 켜고 사람을 끌면 들어 올려 옮겨요. 의자에 놓으면 앉아요.
  - 다른 방 의자면 25초쯤 앉아 있다가 일어나서 제 방으로 걸어 돌아가요. 쉼터·침대에 놓으면 거기서 쉬다가 돌아가요.
  - 의자가 아닌 바닥에 놓으면 잠깐 서 있다가 돌아가요.
  - 사람을 그냥 누르면 ❤ 가 떠요(쓰다듬기). ✋ 를 다시 누르면 꺼져요.

사람 모델은 `models/p<번호>.js`에 들어 있어요. GLB를 base64로 넣어 두어 `file://`에서도 읽혀요.

- 1~16번은 Meshy로 만든 캐릭터예요. 1~6번은 동작을 직접 넣었고, 7~16번은 1·2번 동작을 옮겨 붙였어요.
- 17~24번은 빛식물 프로젝트 캐릭터예요. 서기·걷기·앉기·손 흔들기·졸기·잠자기는 빛식물 자기 동작이고, 나머지(타자 등)는 Meshy 동작을 옮겨 붙였어요.
- 화면에 나오는 캐릭터만 그때그때 불러와요. 그동안은 도형 사람으로 그려요.
- 다시 만들 때는 `tools/build-people.js`를 써요. 하는 일:
  - 텍스처를 1024 한 장에 다시 늘어놓아요. UV 조각마다 여백을 두어서, 멀리서 볼 때 옆 조각 색이 섞여 이음매가 선으로 보이지 않게 해요. 화면은 사람 텍스처를 밉맵 2단계보다 흐리게 보지 않아요(`TEX_MAX_LOD`).
  - UV 이음매에서 갈라진 법선을 이어 붙여요 (이음매마다 빛이 끊겨 줄처럼 보이지 않게).
  - 동작은 뼈마다 기본자세에서 돈 만큼을 월드 기준으로 옮겨 붙여요. 뼈대마다 기본자세(T자세·A자세, 뼈 축)가 달라도 같은 자세가 나와요. 15fps·16비트로 줄여요.
  - 걷기 동작의 발 속도(`walkV`)를 재 두어, 다리 길이가 달라도 발이 미끄러지지 않게 걷는 빠르기를 맞춰요.
  - 만든 파일은 `~/.claude/workroom/models/`에 두고, 바꾼 뒤에는 `office3d.js`의 `MODEL_VER`를 올려요 (브라우저 캐시).

## 다른 사람에게 공유하기

현황판(뷰어) 코드만 이 저장소에 있어요. 대화 기록·회의록·열쇠 같은 데이터는 `.gitignore`로 빠져 있어서, 받은 사람 컴퓨터에는 그 사람의 Claude Code 세션만 보여요.

받는 사람이 Claude Code에게 이렇게 부탁하면 돼요.

```
https://github.com/chunryou-delicate/AI-news 저장소의 workroom-dashboard 브랜치에 있는
workroom 폴더(업무방 현황판)를 내 컴퓨터에 설치해 줘.
git clone -b workroom-dashboard https://github.com/chunryou-delicate/AI-news.git 한 다음
node workroom/deploy.js 를 실행하고, ~/.claude/workroom/현황판.html 을 브라우저로 열어 줘.
```

- Node.js와 git이 있어야 해요.
- 방 목록은 처음에 그 사람 프로젝트 폴더 이름으로 자동으로 만들어져요. 이 저장소의 `rooms.json` 경로가 그 컴퓨터에 없으면 자동으로 그렇게 해요.
- 다른 컴퓨터 동기화, 폰·외부 링크는 따로 켜야 하는 기능이에요. 아래 절을 보세요.

## 설치

Node.js가 필요해요.

```sh
node workroom/deploy.js
```

`~/.claude/workroom/`에 코드를 복사하고, `~/.claude/settings.json`에 현황판 훅을 추가해요. 다른 훅(예: Orca 훅)은 그대로 둬요. 그다음 `~/.claude/workroom/현황판.html`을 브라우저로 열면 돼요.

- 방 목록은 `~/.claude/workroom/rooms.json`에서 바꿔요. 세션의 작업 폴더가 `paths` 아래에 있으면 그 방에 앉아요. 어느 방에도 안 맞으면 "기타" 라운지로 가요.
- 훅 빼기: `node ~/.claude/workroom/install-hooks.js --uninstall`

## 폰에서 보기 (같은 와이파이)

`node ~/.claude/workroom/server.js`를 띄우면 같은 와이파이의 폰에서 현황판을 볼 수 있어요. 처음 띄울 때 `server.json`에 열쇠(token)를 만들고, 폰에서 열 링크(`http://<PC 주소>:8790/?k=<열쇠>`)를 보여 줘요. `node server.js --link`로 링크를 다시 볼 수 있어요.

- 현황판 화면과 그 화면이 읽는 파일만 내보내고, 열쇠가 맞아야 열려요. 한 번 열면 30일 동안 기억해요.
- PC를 켤 때마다 자동으로 띄우려면 `node workroom/deploy.js --server` 를 한 번 실행하세요 (Windows 시작프로그램 / 리눅스 systemd).

## 밖에서 폰으로 보기 (Cloudflare 임시 터널)

`bin/cloudflared(.exe)`(Cloudflare 공식 배포본)를 두고 `node ~/.claude/workroom/tunnel.js`를 띄우면 server.js 화면을 https://…trycloudflare.com 바깥 주소로 이어 줘요. 열쇠가 있어야 열리는 건 같아요.

- 임시 터널이라 다시 띄울 때마다 주소가 바뀌어요. 새 주소가 나오면 `tunnel.json`에 적고, 동기화용 비공개 저장소 main 브랜치의 `LINK.md`에도 링크를 적어 둬요. 폰의 GitHub에서 그 파일을 열면 늘 지금 링크가 있어요.
- `node tunnel.js --link`로 지금 링크를 볼 수 있어요.
- 링크(열쇠 포함)를 아는 사람은 누구나 볼 수 있으니 남에게 보내지 마세요. 열쇠를 바꾸려면 `server.json`을 지우고 server.js 와 tunnel.js 를 다시 띄우세요.

## 다른 컴퓨터 세션도 같이 보기

다른 컴퓨터(예: 회사 노트북)의 세션을 이 현황판에 "<컴퓨터 이름> 층"으로 함께 보여 줄 수 있어요. 주고받는 길은 **비공개** git 저장소예요. 이 저장소는 공개라서 기록을 여기에 올리면 안 돼요.

- 보내는 컴퓨터는 자기 기록(세션 상태, 말, 회의록) 스냅숏을 저장소의 `m/<컴퓨터 키>` 브랜치에 최대 1분에 한 번 덮어써요. 커밋 1개만 유지해서 기록이 쌓이지 않아요.
- 받는 컴퓨터는 1분마다 다른 컴퓨터 브랜치를 받아 와요. 받은 기록은 `~/.claude/workroom/remote/`에 들어가요.
- 보내는 컴퓨터에서는 방 목록을 따로 정하지 않아도 돼요(`--auto-rooms`). 세션의 프로젝트 폴더(가장 바깥 git 저장소, 없으면 작업 폴더) 이름으로 방이 생겨요.
  - git 저장소가 아닌 큰 폴더 안에 하위 저장소가 있으면 방이 따로 생겨요. 한 방으로 묶으려면 `rooms.json` 에 그 큰 폴더를 같이 적어요.
    `{"auto": true, "rooms": [{"name": "큰프로젝트", "paths": ["C:\\Users\\<나>\\Desktop\\큰프로젝트"]}]}` 처럼 적으면 그 아래 세션은 모두 "큰프로젝트" 방에 앉고, 나머지는 전처럼 프로젝트 폴더 이름으로 방이 생겨요.
- 회사 컴퓨터에서 보낼 때는 업무 대화 내용이 개인 저장소로 나간다는 점을 회사 보안 규정과 함께 확인하세요.

보내는 쪽 (git, Node.js, 비공개 저장소에 접근할 GitHub 로그인이 필요해요):

```sh
git clone -b workroom-dashboard https://github.com/chunryou-delicate/ai-news.git
cd ai-news
node workroom/deploy.js --machine "회사 노트북" --sync <비공개 저장소 주소> --push --auto-rooms
```

받는 쪽 (Windows에서는 `--schedule`로 1분마다 받기를 작업 스케줄러에 등록해요):

```sh
node workroom/deploy.js --machine "집 컴퓨터" --sync <비공개 저장소 주소> --pull --schedule
```

모든 컴퓨터가 주고받기 (컴퓨터마다 자기 현황판): 각 컴퓨터가 자기 세션은 직접 보여 주고, 다른 컴퓨터 현황은 비공개 저장소에서 받아 "<컴퓨터 이름> 층"으로 붙여요.

```sh
node workroom/deploy.js --machine "회사 노트북" --sync <비공개 저장소 주소> --push --pull --server --local
```

- `--server`: 이 컴퓨터 현황판 서버(server.js)를 로그인할 때 자동으로 뜨게 등록하고 지금 다시 띄워요. Windows는 시작프로그램 폴더, 리눅스는 systemd 사용자 서비스(`workroom-server.service`)를 써요. 서버가 떠 있는 동안 1분마다 동기화하니까 리눅스에서도 `--schedule` 이 필요 없어요. 끄기: `--unserver`
- `--local`: 서버가 이 컴퓨터에서만 열려요. 회사 노트북처럼 같은 망의 다른 기기에서 보이면 안 될 때 써요. 빼면 같은 와이파이의 폰에서도 열려요.
- 여는 법: `node ~/.claude/workroom/server.js --open` (열쇠가 든 링크를 화면에 찍지 않고 브라우저로 바로 열어요. 한 번 열면 30일 동안 `http://localhost:8790` 으로 열려요.)
- 컴퓨터 이름(`--machine`)은 처음 정한 이름을 그대로 쓰세요. 바꾸면 같은 컴퓨터가 새 층으로 하나 더 생겨요. 이름을 빼면 `sync.json` 의 전 이름을 써요.

- **회의록 보관:** 동기화를 켠 컴퓨터는 자기 회의록(.md)을 비공개 저장소 main 브랜치의 `minutes/<컴퓨터>/<방>/<날짜>.md`로 커밋해요. 바뀐 게 있으면 10분마다(`sync.json`의 `archiveMinutes`), 회의가 끝나면 바로 올려요. 끄려면 `"archive": false`.
- 끄기: `~/.claude/workroom/sync.json` 지우기, 작업 스케줄러는 `node workroom/deploy.js --no-hooks --unschedule`
- 동기화 결과는 `~/.claude/workroom/sync-status.json`, 오류는 `error.log`에 남아요

## 회의록 트리 (오른쪽 패널)

방에 들어가지 않아도 오른쪽 패널 **회의록**에서 `층(컴퓨터) ▸ 방 ▸ 날짜(최신 먼저) ▸ 그날 회의록`을 펼쳐 볼 수 있어요. 이 컴퓨터 층이 맨 위예요. 날짜를 펼치면 방 안 회의록처럼 대화/전체, 더 보기, 회의록 저장이 돼요. 펼친 상태는 브라우저에 기억하고, 방에 들어가면 그 방의 오늘 날짜를 펼쳐 둬요.

- 이 컴퓨터: `minutes/<방>/<날짜>.jsonl` (30일 지나 지워진 날짜는 `.md`)
- 다른 컴퓨터: 동기화가 회의록 보관 때 받아 두는 비공개 저장소 main 사본 `archive-repo/minutes/<컴퓨터>/<방>/<날짜>.md` (컴퓨터마다 10분마다 올려요)
- 오늘 것은 실시간 기록(`logs/<방키>.js`)을 써요
- `hook.js`가 목록 `minutes-index.js`와 지난 날짜 `minutes-js/<id>.js`를 만들어요 (`file://`로 열어도 읽히게). 동기화 뒤와 훅 이벤트 때(1분에 한 번) 새로 만들어요.

## 세션에 지시 보내기

서버로 연 현황판에서 세션(확인할 일 항목이나 사람)을 누르면 창 아래에 **지시 보내기** 칸이 있어요. 적고 Enter 를 치면:

- **이 컴퓨터 세션:** Orca 명령줄(`orca terminal send`)로 그 세션 터미널에 바로 입력하고 Enter 를 쳐요. 셸에 명령으로 들어가지 않게, Orca 가 에이전트(Claude 등)가 돌고 있다고 알려 주는 터미널에만 넣어요. 채팅 탭 세션은 아직 안 돼요.
- **다른 컴퓨터 세션:** 비공개 동기화 저장소로 보내고, 그 컴퓨터가 동기화할 때(보통 1~2분) 자기 Orca 로 넣은 뒤 받음 표시를 돌려줘요. 그 사이에 같은 세션에 더 보낸 지시는 앞의 것에 "(추가 지시)"로 이어 붙여 한 번에 넣어요(똑같은 말은 한 번만, 창에는 "합쳐서 들어감"). 두 시간 안에 못 받으면 넣지 않아요. 보내는 컴퓨터는 `push`, 받는 컴퓨터는 `pull` 이 켜져 있어야 해요.
- 창에 최근 보낸 것 세 개와 상태(들어감 · 전달 대기 · 못 넣음)가 보여요. 기록은 `send-log.json` 에만 남아요.
- 현황판 열쇠가 있는 사람은 지시도 보낼 수 있으니 링크를 남에게 주지 마세요. 끄려면 `server.json` 에 `"send": false`, 다른 컴퓨터 지시를 받지 않으려면 `sync.json` 에 `"acceptSend": false`.
- 명령줄로도 보낼 수 있어요: `node ~/.claude/workroom/send.js <세션ID> <지시>` (AI News 세션이 대신 전할 때). `--json` 을 앞에 붙이면 결과를 JSON 한 줄로 줘요.
- 세션 창의 **마지막 답변**은 앞 200자가 아니라 전체 글이에요. 그 방 회의록에서 같은 답변을 찾아 보여 주고, 못 찾으면(지난 기록) 앞부분만 보여요.

## 사람 고용 (방에 새 세션)

서버로 연 현황판에서 방에 들어가면 오른쪽 위에 **이 방 직원** 카드와 **+ 사람 고용** 단추가 있어요. 이름을 적고 고용을 누르면:

- **이 컴퓨터 방:** 그 방 프로젝트 폴더(`rooms.json` 의 `paths`, 없으면 그 방 세션이 쓰던 폴더)에 Orca 새 탭을 열고 `claude -n "이름"` 으로 시작해요. 탭 제목과 세션 이름이 그 이름이 되고, 곧 그 방에 사람으로 들어와요. 일은 그 사람을 눌러 지시 보내기로 주면 돼요.
- **다른 컴퓨터 방:** 지시 보내기와 같은 길로 그 컴퓨터에 보내고, 그 컴퓨터가 동기화할 때 자기 Orca 로 띄워요 (그 컴퓨터 현황판 코드도 최신이어야 해요).
- 라운지(기타)는 정해진 폴더가 없어서 안 돼요. 폴더가 Orca 에 프로젝트로 등록돼 있어야 해요 (그 안의 작업 폴더만 등록돼 있으면 그쪽에 열어요).
- 이름은 셸에 들어가므로 글자·숫자·빈칸·`._()·-` 만 남기고 40자로 잘라요. 명령줄: `node ~/.claude/workroom/send.js --hire <방> <이름>`.
- 지시 보내기를 끄면(`"send": false`) 고용도 같이 꺼져요.
- 명령줄로 첫 지시까지: `node ~/.claude/workroom/send.js --hire <방> <이름> -- <첫 지시>` (Claude 가 입력을 받을 준비가 될 때까지 기다렸다가 넣어요).
- Orca 명령줄이 느린 컴퓨터(터미널 목록이 수십 초)도 되게, 그 세션 터미널 하나만 확인하고(`orca terminal show`) 서버는 send.js 를 따로 띄운 프로세스로 한 번에 하나씩 돌려요. 그래서 보내는 동안 현황판이 멈추지 않아요.

## 직원 해고 (두 단계)

1. **해고(숨기기):** 사람을 눌러 연 세션 창 맨 아래 **직원 해고** → 확인 창에서 **해고**.
   - 현황판(사무실 그림·확인할 일·직원 목록·텔레그램 알림)에서만 안 보여요. 세션은 그대로 돌아요.
   - PC·폰·다른 컴퓨터 현황판에서도 같이 숨어요(`acks.json` 의 `fire:<세션ID>`, 30일).
2. **영구 해고(탭 닫기):** 직원 탭 ▸ **해고** 목록에서 **영구 해고** → 확인 창에서 한 번 더.
   - 그 세션의 Orca 탭을 닫아요. 에이전트가 일하는 중이어도 닫아요. 대화 기록은 남아서 `claude --resume` 으로 다시 부를 수 있어요.
   - 다른 컴퓨터 세션은 동기화로 보내 그 컴퓨터가 닫아요(1~2분).
   - Orca 탭이 없는 세션(채팅 탭·Orca 밖)은 닫을 수 없어서 숨긴 채로 둬요.
- 같은 목록의 **복직**을 누르면 다시 보여요.
- 닫은 세션은 그 자리에서 '종료'로 적어요. 강제로 닫으면 Claude 퇴장 훅이 안 불려서예요.
- Claude 가 살아 있는 세션마다 남기는 기록(`~/.claude/sessions`)에 없는 세션은 2분 뒤 '종료'로 봐요. 유령으로 남지 않게요.
- 명령줄: `node ~/.claude/workroom/send.js --close --force <세션ID>`

## 직원 이름 바꾸기

세션 창 머리의 **✎ 이름**을 누르고 새 이름을 적으면, 그 세션에 `/rename <새 이름>` 을 넣어요.

- Claude 세션 이름이 바뀌고, 현황판 이름도 따라 바뀌고, Orca 탭 제목도 같이 바뀌어요.
- 다른 컴퓨터 세션은 동기화로 보내요. 그 컴퓨터가 예전 현황판이어도 `/rename` 지시로 들어가서 바뀌어요.
- Orca 터미널에서 도는 세션만 돼요.
- 명령줄: `node ~/.claude/workroom/send.js --rename <세션ID> <새 이름>`

## 카드에서 바로 답하기

서버로 연 현황판의 **확인할 일** 카드 아래에 갈래마다 자주 쓰는 짧은 답이 있어요 (승인 대기: "응 진행해"·"아니, 하지 마", 질문: "알아서 판단해서 해", 완료 보고: "이어서 진행해"·"커밋하고 푸시해", 막힘: "다시 해 봐"). 실수로 보내지 않게 한 번 누르면 "한 번 더 →" 로 바뀌고 4초 안에 다시 눌러야 보내요. **✎ 직접**을 누르면 한 줄로 적어 보낼 수 있어요. 보내는 길은 지시 보내기와 같아요.

카드에는 그 차례에 생긴 **변경 요약**(커밋 수·바뀐 파일과 줄, 커밋 안 한 파일 수)도 붙어요. 요청을 받을 때와 차례를 마칠 때 그 폴더의 git 을 비교해서 세요(git 저장소인 폴더만).

## 일감 보드와 예약 업무 (일감 탭)

- **일감:** 할 일을 적어 두면 **할 일**에 쌓여요. **보내기…**로 방과 사람을 고르거나 "새로 고용…"에 이름을 적으면 그 사람에게 보내거나 새로 고용하며 첫 지시로 넣어요(**진행 중**). 그 세션이 차례를 마치면 **확인 대기**로 넘어가고, **완료**를 누르면 끝나요. 완료는 최근 50개까지 남아요.
- **예약 업무:** 방·이름·지시·시각·요일을 정해 두면 그 시각에 그 방에서 이름이 같은 사람에게 보내고, 없으면 그 이름으로 새로 고용하며 보내요. 보낸 것은 일감 보드에도 남아요. 현황판 서버가 켜져 있어야 하고, 꺼져 있던 동안 지난 예약은 30분 안에 켜졌을 때만 늦게라도 보내요.
- 일감과 예약은 서버가 떠 있는 컴퓨터의 `tasks.json` 에만 있어요 (저장소에 안 올라가요).

## 보고 탭 (사용량·하루 요약·활동 히트맵)

- **사용량:** 컴퓨터마다 5시간·7일 한도(초기화까지 남은 시간)와 컨텍스트가 많이 찬 세션. 한도는 그 컴퓨터에서 `node ~/.claude/workroom/install-hooks.js --statusline` 을 한 번 해 둬야 보여요. 상태줄 사이에 `statusline.js` 를 끼워 기록하고, 원래 상태줄 명령(Orca 등)은 그대로 이어서 불러요. 되돌리기는 `--statusline-off`. 컨텍스트는 그 전에도 마지막 응답의 토큰 수로 보여요(창 크기를 몰라서 퍼센트 대신 "약 150k 토큰"처럼).
- **하루 요약:** 날짜마다 컴퓨터 ▸ 방별 요청·답·커밋 수, 활동한 시간대, 사람마다 마지막 답 앞부분. ◀ 전날 · 다음날 ▶ 로 넘겨요.
- **활동 히트맵:** 최근 14일 × 24시간, 색이 진할수록 요청·답이 많았던 때. 컴퓨터별로 거를 수 있어요.
- 집계는 `hook.js` 가 1분에 한 번 `activity.js` 로 만들어요 (이 컴퓨터 회의록 + 다른 컴퓨터 보관 회의록·실시간 로그).

## 직원 탭 도구 (다른 컴퓨터 업데이트·세션 정리)

- **⟳ 다른 컴퓨터 업데이트:** 컴퓨터마다 고른 세션(보통 AI News 방)에 "git pull 하고 `workroom/UPDATE.md` 절차대로 해" 라는 지시를 보내요. 절차와 하지 말 것은 [UPDATE.md](UPDATE.md) 에 있어요.
- **🧹 세션 정리:** 1시간·6시간·하루 넘게 내 차례나 대기로 둔 세션을 모아 **확인 처리**(확인할 일에서 치우기)하거나 **탭 닫기**(두 번 눌러야 닫혀요)해요. 일하는 중이거나 답을 기다리는 세션은 고르지 않고, 대화 기록은 남아서 `claude --resume` 으로 다시 열 수 있어요. 다른 컴퓨터 세션은 동기화로 보내 그 컴퓨터가 닫아요. 명령줄: `node ~/.claude/workroom/send.js --close <세션ID>...`

## 텔레그램 알림

승인 대기·질문·막힘이 새로 생기면 텔레그램으로 알리고, 20분 지나도 그대로면 한 번 더 알려요. 알림의 단추(빠른 답)를 누르거나 알림에 **답장**으로 쓰면 그 세션에 지시로 들어가요. 봇에게 "상태" 라고 보내면 지금 기다리는 것 목록을 보여 줘요.

1. 텔레그램에서 @BotFather 로 봇을 만들고 받은 토큰을 `~/.claude/workroom/notify.json` 에 직접 적어요: `{ "telegram": { "token": "<토큰>", "chatId": "" }, "remindMin": 20, "withText": true }`
2. 만든 봇에게 아무 말이나 한 번 보내고 `node ~/.claude/workroom/notify.js --find-chat` (대화방 번호를 찾아 적어요), `node ~/.claude/workroom/notify.js --test` (시험 알림).
3. 현황판 서버가 떠 있는 동안 돌아요. 처음 켰을 때 이미 있던 것과 6시간 넘은 것은 알리지 않아요.

- 설정한 대화방에서 온 것만 받고, 토큰은 화면이나 `error.log` 에 남기지 않아요. `notify.json` 은 저장소에 올리지 마세요.
- 알림은 한 컴퓨터에서만 켜요(다른 컴퓨터 세션도 동기화로 다 보이니까). `"withText": false` 면 알림에 질문 내용을 빼고 방·이름만 보내요.

## 기록이 쌓이는 곳 (`~/.claude/workroom/`, 저장소에는 안 올라감)

- `sessions/<세션ID>.json`: 세션별 상태
- `minutes/<방>/<날짜>.jsonl`: 회의록 원본. 도구 사용 내역은 `<날짜>.tools.jsonl`에 따로 쌓이고, 원본은 30일 지나면 지워요
- `minutes/<방>/<날짜>.md`: 사람이 읽는 회의록. 자동으로 다시 써져요
- `meetings/<이름>.json`: 오케스트레이션 의장 세션이 남기는 회의 상태 파일

## 회의 상태 파일 형식

의장 세션이 `~/.claude/workroom/meetings/<이름>.json`에 단계마다 덮어써요.

```json
{
  "room": "New world",
  "agenda": "002 엔진과 언어",
  "round": "r1",
  "phase": "1라운드 입장문 작성 중",
  "waitingForUser": false,
  "waitingReason": "",
  "chair": { "sessionId": "…", "orcaAgentSessionId": "…" },
  "roles": [
    { "role": "world", "label": "세계관", "agent": "claude", "state": "working", "terminal": "structworker_…", "output": "docs/agenda/002/r1-world.md" }
  ],
  "updatedAt": 1792860000000
}
```

- `round`: r1, r2, synthesis, critic, wrapup, done 중 하나
- `roles[].state`: waiting, working, done, error 중 하나
- 역할은 `terminal`(Orca 워커 handle), `paneKey`, `tabId`, `sessionId` 중 하나로 실제 세션과 짝지어요
- 회의가 끝나면 `round`를 `done`으로 두거나 파일을 지워요
